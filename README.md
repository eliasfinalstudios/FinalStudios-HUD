# FINAL STUDIOS | Advanced HUD

A modern and fully customizable FiveM HUD for your server.

Preview: https://www.youtube.com/watch?v=2U5g8sxEVn0

## Features

- Player information, ID and player count
- Cash and bank balance display
- Job, hunger and thirst indicators
- Radio and microphone indicators
- Modern vehicle speedometer
- Fuel, engine and vehicle body condition display
- Individually movable HUD elements
- Customizable colors and sizes
- Customizable minimap (Round & Square)
- 5 languages: German, English, French, Spanish and Polish

## Individual HUD Customization

Every player can fully customize their HUD according to their own preferences.

Positions, sizes, colors, visibility and various other design settings can be adjusted directly through the in-game HUD menu.

This allows every player to create their own personalized HUD experience.
